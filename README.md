# Microsserviços com Node.js 🚀

Este repositório contém exemplos e práticas de implementação de **microsserviços utilizando Node.js**, com foco em arquitetura distribuída, escalabilidade e boas práticas de desenvolvimento.

---

## 📌 Objetivo
Demonstrar como construir aplicações baseadas em microsserviços usando **Node.js**, explorando:
- Comunicação entre serviços
- Organização modular
- Escalabilidade e manutenção
- Integração com banco de dados
- Boas práticas de desenvolvimento

---

## 🛠️ Tecnologias Utilizadas
- [Node.js](https://nodejs.org/) – Ambiente de execução JavaScript
- [Express](https://expressjs.com/) – Framework para criação de APIs
- [Docker](https://www.docker.com/) – Containerização e orquestração
- [MongoDB](https://www.mongodb.com/) – Banco de dados NoSQL
- [REST](https://restfulapi.net/) – Padrão de comunicação entre serviços
